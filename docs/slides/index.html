Filosofia Unix: ferramentas pequenas, que fazem uma coisa bem feita e se combinam.

Buscando: grep (conteúdo) e find (arquivos)

$ grep "root" /etc/passwd
$ grep -i "erro" /var/log/syslog | head -n 3
$ grep -c bash /etc/passwd
$ grep -rn "Total" ~
$ find ~ -name "*.txt"
$ find /etc -name "*.conf"
$ find ~ -maxdepth 1 -type d

grep: -i ignora maiúsculas/minúsculas · -r recursivo · -n número da linha · -v inverte · -c conta

Permissões: quem pode o quê

-rwxr-xr--1 ana alunos 512 out 16 notas.sh
tipo- arquivo · d diretório
donorwx: lê, escreve, executa
grupor-x: lê e executa
outrosr--: só lê

r = read (ler) · w = write (escrever) · x = execute (executar; num diretório, permite entrar)

Mudando permissões com chmod

Clique nos bits e veja o número mudar (r=4 w=2 x=1):

$ cd ~
$ touch script.sh
$ ls -l script.sh
$ chmod 755 script.sh
$ ls -l script.sh
$ chmod go-rx script.sh
$ ls -l script.sh

Para um script rodar, ele precisa da permissão x!

Parte 4

Shell Script

automatizando o que você faria à mão

O primeiro script, em 3 passos

#!/bin/bash
# Meu primeiro script
echo "Olá, $USER! Hoje é $(date +%d/%m/%Y)."
  • 1. escrever (nano ola.sh: Ctrl+O salva, Ctrl+X sai)
  • 2. dar permissão de execução
  • 3. executar com ./: o diretório atual não está no PATH
$ ./ola.sh
$ chmod +x ola.sh
$ ./ola.sh
$ bash ola.sh
O primeiro ./ola.sh falha de propósito (sem permissão x). #!/bin/bash é o shebang: diz qual interpretador usar.

Variáveis e aspas

nome="Ana"          # SEM espaços no =
echo "Olá, $nome"
hoje=$(date +%A)    # substituição de comando
echo "Hoje é $hoje"
echo 'Aspas simples: $nome'
echo "Soma: $((2 + 3))"
  • nome = "Ana" dá erro: o shell acha que nome é um comando
  • Aspas duplas expandem variáveis; aspas simples não
  • $(comando) guarda a saída de um comando
  • $(( )) faz contas com números inteiros

Entrada do usuário e argumentos

read -p "Qual sua idade? " idade
echo "Você tem $idade anos"
echo "Daqui a 10 anos: $((idade + 10))"
$1, $2...argumentos (./script.sh a b)
$#quantidade de argumentos
$@todos os argumentos
$0nome do script
$?código de saída do último comando

Condicional: if

idade=20
if [ "$idade" -ge 18 ]; then
  echo "Maior de idade"
else
  echo "Menor de idade"
fi
NúmerosTextosArquivos
-eq igual= igual-f é arquivo
-ne diferente!= diferente-d é diretório
-lt -le menor-z vazio-e existe
-gt -ge maior-n não vazio-x executável

Os espaços dentro de [ ] são obrigatórios: [ "$a" -eq 1 ]

Laços: for e while

for i in 1 2 3; do
  echo "Número $i"
done
for arq in *.txt; do
  echo "Encontrei: $arq"
done
contador=1
while [ $contador -le 3 ]; do
  echo "Volta $contador"
  contador=$((contador + 1))
done

Código de saída: deu certo?

$ ls /etc > /dev/null
$ echo $?
$ ls /nao_existe 2> /dev/null
$ echo $?
$ mkdir -p ~/backup && echo "criado!"
$ ls /nao_existe 2> /dev/null || echo "falhou!"
  • 0 = sucesso · qualquer outro número = erro
  • exit 1 num script sinaliza falha
  • a && b: roda b só se a deu certo
  • a || b: roda b só se a falhou

Demo: backup.sh junta tudo

#!/bin/bash
# Uso: ./backup.sh DIRETORIO
origem="$1"
if [ -z "$origem" ]; then
  echo "Uso: $0 DIRETORIO"; exit 1
fi
if [ ! -d "$origem" ]; then
  echo "Erro: '$origem' não é um diretório."; exit 2
fi
destino="backup_$(date +%H%M%S)"
mkdir -p "$destino"
total=0
for arq in "$origem"/*.txt; do
  [ -f "$arq" ] || continue
  cp "$arq" "$destino/"
  echo "Copiado: $arq"
  total=$((total + 1))
done
echo "Backup: $total arquivo(s) em $destino"
$ chmod +x backup.sh
$ ./backup.sh
$ echo $?
$ ./backup.sh nao_existe
$ ./backup.sh aula

Exercício 2 · saudacao.sh

  1. Receba um nome como argumento: ./saudacao.sh Maria
  2. Se nenhum nome for passado, pergunte com read
  3. Imprima: Olá, <nome>! Agora são HH:MM.
  4. Bônus: "Bom dia" (antes das 12h), "Boa tarde" (até as 18h) ou "Boa noite"

Dica: date +%H:%M mostra a hora e [ -z "$1" ] testa se o argumento está vazio.

Gabarito do Exercício 2

nome="$1"
if [ -z "$nome" ]; then
  read -p "Qual o seu nome? " nome
fi
hora=$(date +%H)
if [ "$hora" -lt 12 ]; then
  saudacao="Bom dia"
elif [ "$hora" -lt 18 ]; then
  saudacao="Boa tarde"
else
  saudacao="Boa noite"
fi
echo "$saudacao, $nome! Agora são $(date +%H:%M)."
