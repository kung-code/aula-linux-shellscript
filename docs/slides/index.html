Por que um profissional de TI precisa do terminal?

  • Servidores geralmente não têm interface gráfica: é só você e o terminal
  • Automação: o que você faz 100 vezes à mão, um script faz em 1 segundo
  • DevOps e nuvem: Docker, Kubernetes e CI/CD são operados por linha de comando
  • Segurança, dados e desenvolvimento: as ferramentas vivem no terminal

Uma única árvore, a partir de /

/                 raiz de tudo├── home/│   └── aluno/    sua casa (~)├── etc/          configurações├── bin/  usr/    programas├── var/log/      logs├── tmp/          temporários└── root/         casa do administrador
  • Não existe C:\: tudo fica pendurado no /

Terminal essencial

Abra o seu terminal ou o terminal de prática no navegador ↗

Onde estou? Quem sou eu? O que tem aqui?

$ pwd
$ whoami
$ ls
$ ls -l
$ ls -a
$ ls -lh /etc
  • pwd: print working directory (diretório atual)
  • -l formato longo
  • -a mostra ocultos
  • -h tamanhos legíveis

Navegando com cd

$ cd /etc
$ pwd
$ cd ..
$ cd ~
$ cd -
$ cd

TAB completa nomes! Digite cd Docu e aperte Tab. Use e abuse.

Criando diretórios e arquivos

$ mkdir aula
$ mkdir -p aula/projeto/{scripts,dados}
$ touch aula/notas.txt
$ echo "Minha primeira linha" > aula/notas.txt
$ ls -R aula
  • -p cria os diretórios intermediários (e não reclama se já existir)
  • {a,b} é expansão de chaves: vira a e b

Copiar, mover, renomear e remover

$ cp aula/notas.txt aula/copia.txt
$ mv aula/copia.txt aula/backup.txt
$ ls aula
$ cp -r aula aula_bkp
$ rm aula/backup.txt
$ rm aula_bkp
$ rm -r aula_bkp

Não existe lixeira! O rm apaga de verdade. Nunca rode comandos da internet sem entender o que fazem (principalmente rm -rf e sudo).

Lendo arquivos

$ cat /etc/hostname
$ head -n 3 /etc/passwd
$ tail -n 2 /etc/passwd
$ wc -l /etc/passwd
catmostra tudo
head / tailinício / fim
lessrolar com as setas (q sai)
wc -lconta linhas

Pedindo ajuda e atalhos essenciais

$ man ls
$ wc --help
$ history | tail -n 4
Tabcompleta comandos e nomes
↑ ↓navega no histórico
Ctrl+Cinterrompe o comando
Ctrl+Llimpa a tela
qsai do man e do less

Exercício 1 · Montando o projeto

  1. Vá para a sua home.
  2. Crie, com um único comando: projeto/docs, projeto/src e projeto/testes
  3. Em docs, crie leia-me.txt com a frase Projeto da aula de Linux
  4. Acrescente uma 2ª linha com seu nome (sem apagar a 1ª)
  5. Copie leia-me.txt para src/copia.txt
  6. Renomeie testes para tests
  7. Mostre a árvore: ls -R projeto

Desafio para casa · Meu primeiro projeto no terminal

  1. Na sua home, crie com um único comando: estudos/linux/anotacoes, estudos/linux/exercicios e estudos/linux/arquivo-morto
  2. Em anotacoes, crie comandos.txt com 5 comandos que você aprendeu, um por linha (echo com > e >>)
  3. Copie comandos.txt para exercicios/ com o nome revisao.txt
  4. Crie 3 arquivos vazios em arquivo-morto/ e depois apague só um deles
  5. Mostre o resultado: ls -R estudos, wc -l e head -n 2 nos arquivos
  6. Bônus: descubra no man ls como listar ordenando por tamanho
  • Faça no terminal de prática ↗ (o desafio está na aba Roteiro)
  • Ou no Git Bash: no Windows, ele vem junto com o Git. No Linux e no macOS, use o próprio terminal
  • Entrega: copie a saída do passo 5 (ou um print) e envie no canal da turma
