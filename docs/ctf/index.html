Missão Servidor Pinguim

Um CTF (Capture The Flag) para praticar Linux e Shell Script num terminal que roda inteiro no seu navegador.

  • 8 níveis, do cat ao primeiro script com laço
  • Encontre as FLAG{...} e envie com enviar
  • Travou? Use as dicas (custam um pouco de pontos)

Cada codinome gera flags diferentes (copiar a flag do colega não funciona 😉). Use um apelido, não seu nome completo. O progresso fica salvo só neste navegador.

Níveis

    Cola rápida

    ls -la
    lista tudo, com detalhes
    cd dir
    entra no diretório (cd .. sobe)
    cat arq
    mostra o conteúdo
    find . -name "x"
    procura arquivos
    grep txt arq
    procura texto
    chmod u+r arq
    muda permissões
    cmd1 | cmd2
    pipe: saída vira entrada
    nano · vi arq
    edita (no vi: i escreve, Esc :wq salva e sai)
    man cmd
    manual do comando

    Atalhos: Tab completa · ↑ histórico · Ctrl+C interrompe · Ctrl+L limpa
